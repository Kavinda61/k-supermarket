# 🛒 K-Supermarket Management System

A web-based Supermarket Management System designed to streamline store operations, inventory tracking, sales processing, and role-based user access control.

---

## 🚀 Features

### 👤 Role-Based Access Control
- **Administrator Dashboard:**
  - Full system management (users, products, inventory, sales, reports).
  - Manage staff/employee accounts and access permissions.
- **Staff / Cashier View:**
  - Process customer transactions at POS.
  - Manage product items and stock levels.
  - View daily receipts and invoices.
- **Customer View:**
  - Browse available items, pricing, and category filters.
  - Search products and view promotions/offers.

### 📦 Key Functionalities
- **Product & Inventory Management:** Add, edit, delete, and categorize stock/products.
- **Billing & Checkout System:** Fast item lookup, auto-calculated totals, and receipt generation.
- **Sales & Transaction History:** Track sales records and view transaction logs.
- **Responsive UI:** Clean and intuitive user interface optimized for desktop and mobile viewing.
